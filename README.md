# Flight Price Prediction

This project is about predicting flight ticket prices using machine learning.

I used a flight price dataset and tried different models and preprocessing methods to see which one gives better results.

## Models Used

* Linear Regression
* Decision Tree
* Random Forest
* Extra Trees
* K-Nearest Neighbors
* XGBoost

I also tried different scaling methods and PCA to compare their effects on the models.

## Dataset

The dataset contains information such as:

* Airline
* Source and destination city
* Departure and arrival time
* Number of stops
* Flight duration
* Ticket class
* Days left before departure
* Flight price

## Results

The best results in my experiments were obtained with tree-based models.

The best Random Forest model achieved an **R² score of about 0.99** on the test set.
